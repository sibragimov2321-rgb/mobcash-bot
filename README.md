# MOMENTUM SERVICE — Telegram-бот

Бот повторяет структуру и сценарии из предоставленного видео:

- регистрация с выбором русского или английского языка;
- принятие пользовательского соглашения;
- главное меню из четырёх кнопок;
- пополнение игровых платформ с сохранением игрового ID;
- выбор суммы и способа оплаты;
- отправка чека и ручное подтверждение администратором;
- вывод с реквизитами, QR-кодом кошелька и подтверждением заявки;
- профиль, статистика, история операций и реферальная программа;
- администраторские кнопки подтверждения и отклонения заявок.

## Безопасный запуск

1. Если токен когда-либо попадал на скриншот, отзовите его через
   `@BotFather` → **API Token** → **Revoke current token**.
2. Вставьте новый токен в `.env` после `BOT_TOKEN=`.
3. Запустите `start_bot.cmd`.
4. Отправьте боту `/start`.

Чёрное окно должно оставаться открытым. Для остановки нажмите `Ctrl+C`.

## Развёртывание в Railway

Проект готов к загрузке напрямую с компьютера командой `railway up`.
Файл `.env`, локальная база, виртуальное окружение и материалы анализа видео
исключены из загрузки.

1. Войдите в Railway командой `railway login`.
2. Создайте проект и пустой сервис командой `railway init`.
3. В Variables сервиса добавьте значения из локального `.env`.
4. Добавьте к сервису Volume с точкой монтирования `/data`.
5. Не задавайте `DATABASE_PATH`: бот автоматически сохранит SQLite-базу
   в `${RAILWAY_VOLUME_MOUNT_PATH}/bot.sqlite3`.
6. Выполните `railway up` и проверьте журнал запуска.

Команда запуска и политика автоматического перезапуска находятся в
`railway.toml`. Для Telegram polling-бота не требуется публичный домен или
переменная `PORT`. Не включайте Serverless, иначе постоянно работающий бот
может быть остановлен.

## Настройка платежей

Откройте `.env` и замените тестовые тексты:

```text
PAYMENT_MBANK_DETAILS=Ваши настоящие реквизиты MBANK
PAYMENT_OMONEY_DETAILS=Ваши настоящие реквизиты O!Деньги
PAYMENT_MEGAPAY_DETAILS=Ваши настоящие реквизиты MegaPay
PAYMENT_BALANCE_DETAILS=Ваши настоящие реквизиты Balance
PAYMENT_BAKAI_BANK_DETAILS=Ваши настоящие реквизиты BAKAI BANK
```

Единый QR показывается сразу после выбора суммы. Вариант со статичным
изображением:

```text
PAYMENT_QR_IMAGE=assets/payment_qr.png
```

Для динамического QR можно указать HTTPS-шаблон. Доступные переменные:
`{amount}`, `{original_amount}`, `{account_id}`, `{platform}`.

`{amount}` содержит точную сумму перевода с уникальными копейками `01–99`.
Код резервируется на время оплаты, а `{original_amount}` остаётся суммой,
которая должна быть зачислена на игровой аккаунт.

```text
PAYMENT_QR_URL_TEMPLATE=https://провайдер/pay?amount={amount}&id={account_id}
```

Под QR расположены кнопки `MBANK`, `O!Деньги`, `MegaPay`, `Balance`,
`BAKAI BANK` и `Отмена`. Банковские ссылки также поддерживают переменные:

```text
PAYMENT_MBANK_URL=https://app.mbank.kg/ваша-ссылка
PAYMENT_OMONEY_URL=https://ваша-ссылка
PAYMENT_MEGAPAY_URL=https://megapay.kg/ваша-ссылка
PAYMENT_BALANCE_URL=https://ваша-ссылка
PAYMENT_BAKAI_BANK_URL=https://ваша-ссылка
```

После выбора банка бот показывает две дополнительные кнопки:
`🤖 Android` и `🍎 iPhone`. Для стандартных банков используются официальные
страницы Google Play и App Store. При необходимости ссылки можно переопределить
переменными `PAYMENT_<БАНК>_ANDROID_URL` и `PAYMENT_<БАНК>_IOS_URL`.

## Админ-панель

Панель открывается командой `/admin`. Пользователи из `ADMIN_IDS` при первом
запуске автоматически получают защищённую роль Owner. Владелец может назначать
Управляющих и Менеджеров через модуль `👥 Команда`; назначаемый пользователь
должен предварительно нажать `/start` в боте.

Для сквозного журнала добавьте бота в закрытую Telegram-группу, выполните в ней
команду `/chatid`, затем сохраните полученный ID через
`/admin → ⚙️ Система → 🗂 ID чата логов`.

Карты поддерживают разовые и суточные лимиты, статусы `активна`, `резерв`,
`отключена` и `лимит исчерпан`. При исчерпании суточного лимита следующая
подходящая резервная карта того же банка автоматически становится активной.

Через панель также доступны технические работы, динамическое включение платформ
и банков, статистика, массовая рассылка, контакт поддержки, текст оферты и
проценты расчётной прибыли.

К введённой сумме добавляется комиссия `0,15%`. Платёжные кнопки действуют
5 минут, затем бот удаляет их и запрещает оплачивать по старым реквизитам.
Бот намеренно не использует QR и ссылки из примера: они могут вести на чужой
счёт.

## Настройка сервиса

Основные параметры `.env`:

```text
ADMIN_IDS=6456456621
SERVICE_NAME=MOMENTUM SERVICE
SUPPORT_USERNAME=@username
CURRENCY=KGS
PLATFORMS=1XBET,MELBET,1WIN,MOSTBET,WINWIN,888STARZ
MIN_DEPOSIT=35
MAX_DEPOSIT=500000
MIN_WITHDRAW=500
MAX_WITHDRAW=500000
REFERRAL_PERCENT=1
MIN_REFERRAL_WITHDRAW=500
```

Несколько администраторов указываются через запятую.

## Команды пользователя

- `/start` — регистрация или главное меню;
- `/deposit` — пополнение;
- `/withdraw` — вывод;
- `/profile` — личный кабинет;
- `/requests` — последние заявки;
- `/terms` — соглашение и правила;
- `/language` — сменить язык;
- `/cancel` — отменить текущий ввод;
- `/id` — показать Telegram ID.

## Команды администратора

- `/admin` — показать ожидающие заявки.

Новая заявка автоматически приходит каждому ID из `ADMIN_IDS`. Кнопка
**Подтвердить** меняет статус, обновляет статистику и начисляет реферальный
бонус. При отклонении реферального вывода сумма возвращается пользователю.

## Данные

База находится в `data/bot.sqlite3`. При обновлении старой версии бот добавляет
новые таблицы и поля автоматически, сохраняя пользователей и историю.

Для резервной копии остановите бота и скопируйте папку `data`. Файл `.env`
содержит секретный токен и не должен публиковаться.
