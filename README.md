# Telegram Bot Starter

Независимая заготовка Telegram-бота: профиль, реферальная ссылка, промокоды, каталог, правила и заявки в поддержку.

## Запуск

1. Создайте нового бота через `@BotFather` и сохраните токен.
2. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` и свой Telegram ID в `ADMIN_IDS`.
3. В PowerShell из этой папки выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

## Важно

Шаблон не содержит платежей, ставок, пополнений, выводов или интеграций с финансовыми сервисами. Его можно развивать как бот для легальных услуг, клиентской поддержки, лояльности и информационных продуктов.
