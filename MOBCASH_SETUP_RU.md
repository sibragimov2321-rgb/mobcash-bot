# MOBCASH: настройка отдельного бота

1. Создайте нового бота в `@BotFather` и сохраните его токен только в Railway Variables.
2. Добавьте `BOT_TOKEN`, `ADMIN_IDS`, `SERVICE_NAME=MOBCASH` и `SUPPORT_USERNAME`.
3. Создайте публичный или приватный канал для обязательной подписки.
4. Добавьте бота в этот канал администратором: это обязательно, иначе Telegram не даст проверить подписку.
5. В Railway Variables добавьте:

   - `REQUIRED_CHANNEL` — `@username_канала` или числовой ID приватного канала;
   - `REQUIRED_CHANNEL_URL` — ссылка вида `https://t.me/username_канала` или приглашение в приватный канал.

После развёртывания пользователь увидит кнопку «Подписаться на канал» и кнопку «Проверить подписку». Без действующей подписки меню пополнения и вывода недоступно. Администраторы проходят без проверки.

Никогда не добавляйте `.env`, токен бота, API-ключи, пароли и реквизиты в GitHub.
